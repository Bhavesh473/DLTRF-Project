What is this

DLTRF — Deterministic Log Test Replay Framework

Records every HTTP request your browser makes during a session, then replays those exact requests and compares the responses. If the server returns the same thing, the app is deterministic. If not, something changed.

Divergences are classified by rules in divergence_config.yaml. Every event card shows the exact rule that matched and the reasoning — so you never have to guess why something was flagged. App: Modern Single Page Application (Angular + Node.js + REST). Uses JWTs.
